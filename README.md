# 🍰 Doceria System

Mini sistema de gestão para confeitarias e docerias desenvolvido com **Node.js**, **Express**, **MongoDB** e **JavaScript Vanilla**, preparado para execução local e deploy Serverless na **Vercel**.

Todo o código-fonte e a documentação do projeto estão localizados no diretório [`doceria-system/`](./doceria-system/):

- 🗺️ **Roadmap**: [`doceria-system/Roadmap.md`](./doceria-system/Roadmap.md)
- 📋 **Contexto da Aplicação**: [`doceria-system/Contexto.md`](./doceria-system/Contexto.md)
- 📖 **Documentação da API**: [`doceria-system/api.md`](./doceria-system/api.md)

### Como rodar os testes
```bash
cd doceria-system/backend
npm test
```

### Como rodar a aplicação
```bash
cd doceria-system/backend
npm start
```
Acesse `http://localhost:3000` no seu navegador.
